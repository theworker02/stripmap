# stripmap

Strip identifiers and map tokens for idempotent workflows.

**Site:** https://theworker02.github.io/stripmap/

## Install / run

```bash
git clone https://github.com/theworker02/stripmap.git
cd stripmap
node src/cli.js
node --test
```
